# GIFVERSE 🎞️

**Find your mood. Express it in GIFs.**

GIFVERSE is a dynamic GIF discovery web application that allows users to search for and explore GIFs using the GIPHY API. Built with HTML, CSS, and JavaScript, the application retrieves GIFs in real time and displays them in a responsive gallery.

## Features

- **GIF Search:** Search for GIFs using any keyword.
- **GIPHY API Integration:** Fetches live GIF results from the GIPHY API.
- **Dynamic Rendering:** Displays GIFs directly on the page without reloading.
- **Responsive Gallery:** Organizes GIFs into a clean grid layout.
- **Dark Theme:** Features a modern dark interface with purple accents.
- **Error Handling:** Displays a message if GIF requests fail.

##  Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- GIPHY API
- Fetch API and Async/Await

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd giphy-gif-generator
```

### 3. Configure the GIPHY API

Create a GIPHY developer account and obtain an API key from:

https://developers.giphy.com/

Configure your API key according to the project's local development setup. Never commit API keys or other credentials to GitHub.

### 4. Run the application

Open `index.html` using VS Code Live Server or another local development server.

### 5. Search for GIFs

Enter a keyword in the search bar and click the search button to display matching GIFs.
